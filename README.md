# Hoymiles History Export – Home Assistant Add-on Repository

This repository contains one Home Assistant add-on:

- **[Hoymiles History Export](hoymiles_history_export/)** — backfills
  missing/gap historical Hoymiles solar production data into a Home
  Assistant statistic, using the Hoymiles S-Miles Cloud as the data source.

## Installation

1. In Home Assistant: **Settings → Add-ons → Add-on Store**
2. Top-right **⋮ menu → Repositories**
3. Add this URL:
   `https://github.com/DrdotHouse2106/Hoymiles-History-Export-f-r-HomeAssistant`
4. The **Hoymiles History Export** add-on now appears in the store — install
   it and see [its README](hoymiles_history_export/README.md) for
   configuration and usage.
