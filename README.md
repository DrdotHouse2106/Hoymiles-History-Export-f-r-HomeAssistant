# Hoymiles History Export – Home Assistant Add-on Repository

⚠️ **Proof of Concept, ungetestet in dieser verpackten Form** – siehe
Hinweis in [hoymiles_history_export/README.md](hoymiles_history_export/README.md).
Veröffentlicht, damit andere es ausprobieren, bestätigen was funktioniert,
darauf aufbauen oder melden können, was nicht funktioniert.

Dieses Repository enthält ein Home-Assistant-Add-on:

- **[Hoymiles History Export](hoymiles_history_export/)** – trägt fehlende
  historische Hoymiles-Solar-Ertragsdaten in eine Home-Assistant-Statistik
  nach, mit der Hoymiles S-Miles Cloud als Datenquelle.

## Installation

1. In Home Assistant: **Einstellungen → Add-ons → Add-on Store**
2. Oben rechts **⋮-Menü → Repositories**
3. Diese URL hinzufügen:
   `https://github.com/DrdotHouse2106/Hoymiles-History-Export-f-r-HomeAssistant`
4. Das Add-on **Hoymiles History Export** taucht jetzt im Store auf –
   installieren und die [README](hoymiles_history_export/README.md) für
   Konfiguration und Nutzung lesen.
